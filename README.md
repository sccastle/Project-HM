# HM v1.5.2（扁平版）

这个目录里的**所有文件都在同一层，没有子目录**，把它们全部传到仓库根目录即可，
怎么拖都不会丢结构。

- index.html —— 页面，css 和 js 已经全部内联在里面
- manifest.json —— PWA 清单（装到桌面用）
- service-worker.js —— 离线缓存；页面走「先网络后缓存」，有网时一定是最新版
- *.png —— 图标

上传前，请先把仓库里旧的 `css/`、`js/`、`icons/` 目录和散落在根目录的
`app.js`、`db.js` 这些文件全部删掉，避免新旧混在一起。

更新方法：改完源码后跑 `node build-flat.js`，把 dist-flat 里的文件重新传一遍。
手机上打开后如果版本号没变，进 设置 → 关于 点「清缓存重载」。
